# Design Foundation

## About the Website
This is the IoTrack Learning Kit website. It is an educational platform consisting of 8 main pages designed to deliver learning modules and assessments. The layout is inspired by Coursera, featuring a persistent header and a left sidebar navigation for seamless transitions between learning materials.

## Color Scheme & Gradients
* **Primary Colors**: (To be defined - inherit from main IoTrack branding)
* **Secondary/Accent Colors**: (To be defined - used for buttons, active links, and highlights)
* **Gradients**: Subtle gradients for backgrounds or active states, ensuring readability and a modern feel.
* **Light Mode**: Clean, white/light-gray backgrounds with dark text for high contrast and readability.
* **Dark Mode**: Deep gray/black backgrounds with light text, using subdued accent colors to reduce eye strain during long reading sessions.

## Typography
* **Font Family**: Modern, readable sans-serif (e.g., Inter, Roboto, or system fonts).
* **Headings**: Clear hierarchy (H1 to H6) with consistent font weights to separate sections effectively.
* **Body Text**: Legible size (e.g., 16px) with adequate line height (1.5 - 1.6) for reading long-form learning content.

## Responsive Design
* **Mobile-First Approach**: Ensure all content, assessments, and navigation are easily accessible and functional on mobile devices.
* **Breakpoints**: Standard breakpoints for mobile, tablet, and desktop screens.
* **Layout Shifts**: The left sidebar navigation should collapse into a hamburger menu or bottom navigation bar on smaller screens, maximizing the reading area.

## UI Components
* **Header**: Persistent top header containing branding, user profile, theme toggle (Light/Dark mode), and global actions.
* **Sidebar Navigation**: Fixed left-hand navigation listing all modules (1 to 6) and assessments (Pre and Post) for easy switching. Indicates current active page.
* **Content Area**: Main right-hand section where the learning material is displayed.
